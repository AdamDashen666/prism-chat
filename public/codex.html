登录 ChatGPT

  1. 生成授权链接
  2. 在你的电脑上登录

    用你的 Windows 浏览器打开链接，登录有 Codex 订阅的 ChatGPT 账号并点“继续”。授权完成后浏览器会跳到一个打不开的 localhost 页面，这是正常的。

  3. 粘贴地址

    复制那个打不开的页面地址栏里的完整地址（以 http://localhost:1455/auth/callback?code=… 开头），粘贴到下面。

授权码只能和服务器上保存的校验值配对使用，别人拿到这个地址也无法登录。令牌由服务器直接换取，不会经过你的电脑。

如果你已经在 Windows 上运行过 codex login，可以粘贴 %USERPROFILE%\.codex\auth.json 的完整内容。

导入后服务器会立刻轮换令牌来接管这次登录，Windows 上那份的刷新令牌随之失效（Windows 上的 Codex 需要重新登录）。想让两边都能用，请改用“网页授权”，它会得到一个独立的登录。

API Key

客户端怎么填

  • 接口地址（Base URL）：；API Key 填上面生成的 sk-codex-…。
  • 支持 GET /v1/models、POST /v1/chat/completions（含流式、工具调用、图片输入）、POST /v1/responses。不支持 embeddings、图片生成、语音。
  • Codex 后端不接受 temperature、max_tokens 等采样/长度参数，转发时会自动忽略（响应头 x-codex-proxy-ignored 会列出被忽略的参数）。思考强度用 reasoning_effort。
  • 每个 Key 每分钟最多 120 次请求、同时 6 个。用量算在你的 ChatGPT 订阅额度里，额度用完会返回 429。
