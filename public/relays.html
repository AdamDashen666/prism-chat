RELAY

API 中转

把一个已保存的 API 变成本站的地址和密钥，请求经由本站服务器（美国）转发到原 API，适合国内网络连不上的接口。用法和普通 API 一样：复制地址、密钥和模型填进客户端即可。

新建中转

只能中转你自己保存的 API（管理员授权的不行）。原 API 改了密钥或地址后，在卡片上点“重置密钥”重新读取。

客户端怎么填

  • OpenAI 兼容客户端（ChatBox、Cherry Studio、NextChat、OpenAI SDK 等）：接口地址填卡片上“复制地址”得到的 ，API Key 填“复制密钥”得到的中转密钥。
  • Anthropic / Claude 客户端（Claude Code、Anthropic SDK）：ANTHROPIC_BASE_URL 填 （不带 /v1），密钥同上。
  • 中转是原样转发，不转换格式：原 API 是 OpenAI 格式，中转出来就是 OpenAI 格式；原 API 是 Anthropic 格式，中转出来也是 Anthropic 格式。
  • 限制：每个中转每分钟 300 次、同时 8 个请求，单次请求体 64 MB。请求内容不会被保存，只记录次数和最后使用时间。
